> **Status: in progress.** The design work is still going. There are no 3D models or print files in the repo yet.

## What is it?

Marbew is a marble race that I'm designing myself from scratch and printing on a 3D printer. No kits, no downloaded tracks, every piece is my own design.

## Where it's at

| Part | Status |
|---|---|
| Design | In progress |
| 3D models / print files | Not in the repo yet |
| Bill of materials | Started (`BOM.csv` is set up, no parts listed yet) |
| Printing and assembly | Not started |

## Bill of Materials

The parts list lives in [BOM.csv](BOM.csv). It's just the template for now and will fill up as the design comes together.
